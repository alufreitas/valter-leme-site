# Site — Valter Leme Advogados

Página única, estática (HTML/CSS/JS puros, sem build).

- `index.html` — conteúdo
- `css/style.css` — estilos (responsivo, mobile first)
- `js/main.js` — menu, animações e efeitos de rolagem
- `img/` — fotos (ver `img/FOTOS-LEIA-ME.md`)

## Rodar localmente

```bash
python3 -m http.server 8080
```

Abrir http://localhost:8080
